# Shift Repair — Forge 1.20.1

Исходный проект мода для Minecraft Java Edition 1.20.1, Forge 47.2.0. Это проект для сборки, не готовый `.jar`.

## Реализовано в исходниках
- Блок «Генератор» и предмет-гаечный ключ.
- Запуск ремонта генератора при Shift + ПКМ; удерживайте Shift рядом с генератором, чтобы завершить ремонт примерно за 45 секунд.
- Частицы урона при получении урона игроком.
- Регистрация мода для Forge.

## Важно
- В этой версии 1.85% бонус ключа пока не даёт заметного ускорения из-за округления тиков; его нужно исправить в полноценной сборке.
- Персональный инвентарь из 4 ячеек справа в форме «Г» ещё не реализован.
- Архив не содержит готового `.jar`; для его сборки нужны Java 17, Gradle и доступ к репозиториям Forge.

## Сборка
Из корня проекта выполните `gradle build`. Готовый jar при успешной сборке появится в `build/libs/`.
