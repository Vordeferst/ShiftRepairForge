# Shift Repair — Forge 1.20.1

Это исправленный исходный проект мода для Minecraft Java 1.20.1 и Forge 47.2.0.

Включено в проект: блок генератора, предмет-гаечный ключ, запуск ремонта при Shift + ПКМ и удержании Shift рядом с генератором, частицы при получении урона. Бонус ключа учитывается дробно: скорость ремонта увеличивается на 1,85%.

Важно: это исходный проект, не готовый JAR. После загрузки файлов в GitHub Actions соберёт JAR, который можно скачать в разделе Artifacts. Персональный инвентарь из четырёх ячеек справа в форме «Г» в этом исходнике пока не реализован.
