# Как получить JAR онлайн без установки Java/Gradle

Этот проект содержит GitHub Actions workflow для сборки Forge-мода Minecraft 1.20.1 с Java 17 и Gradle 8.8.

## Один раз настроить
1. Создайте репозиторий на https://github.com/new (например, `ShiftRepairForge`). Можно выбрать Private.
2. Загрузите в репозиторий **содержимое этой папки проекта**: `build.gradle`, `settings.gradle`, `gradle.properties`, `src/` и папку `.github/` с workflow. Не загружайте папку проекта целиком как вложенную папку — файлы должны лежать в корне репозитория.
3. Сделайте commit в ветку `main`.

## Скачать JAR
1. Откройте вкладку **Actions** в репозитории.
2. Выберите workflow **Build Forge mod**.
3. Нажмите **Run workflow** (или дождитесь автоматического запуска после commit).
4. Откройте завершившийся запуск с зелёной галочкой.
5. Внизу страницы найдите **Artifacts** и скачайте `ShiftRepairForge-1.20.1`.
6. Распакуйте скачанный ZIP: внутри будет `.jar`. Поместите его в папку `mods` профиля Minecraft Forge 1.20.1.

Если сборка красная, откройте запуск и пришлите скриншот первой красной ошибки из лога.

## Важно
Это автоматизирует сборку исходников, но не гарантирует, что все задуманные игровые функции уже реализованы. Текущая версия исходников — прототип; интерфейс инвентаря из 4 слотов и визуальная лужа крови в нём пока не реализованы полностью. Сборка требует доступа GitHub Actions к интернету для загрузки зависимостей Forge.
